# Provenance — Quantitative Risk & Decision Science

Decision-tree, VOI, Bayes, risk-aversion and simulation evidence derives from SCM 519 coursework. Reusable code templates and repository organization are portfolio refactoring/extensions and are labeled separately from submitted results.

## Public inspection rule
Every quantitative claim should trace to an executed/source artifact. New code added for portfolio presentation must be identified as refactoring, reconstruction, or extension rather than silently presented as the original submission.
